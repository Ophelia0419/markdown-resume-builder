## Local Preview

`index.html` 파일을 브라우저에서 직접 열거나, 간단한 로컬 HTTP 서버를 실행해 확인할 수 있습니다.

```bash
python3 -m http.server 8000
```

그런 다음 브라우저에서 `http://localhost:8000`을 엽니다.
